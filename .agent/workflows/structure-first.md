# 구조 우선 워크플로우 (분석 기법)\r
\r
PDCA의 Plan 단계에서 **코드를 읽고 구조를 파악하는 구체적 방법**이다.\r
\r
## 읽기 규칙\r
- 관련 파일을 **전부** 읽는다 (일부만 읽지 않는다)\r
- 데이터 흐름을 **시작(크롤링/입력) → 중간(서비스/엔진) → 끝(저장/화면)** 순서로 추적한다\r
- require/import 체인을 따라가며 **실제 사용되는 함수명**을 확인한다\r
- server.js에서 어떤 모듈을 require하고 init하는지 확인한다 (다이어그램과 실제가 다를 수 있음)\r
\r
## 금지 사항\r
- 파일 1~2개만 보고 전체를 추정하지 않는다\r
- 이전 대화 컨텍스트를 맹신하지 않는다 — 반드시 현재 코드를 직접 확인한다\r
- 구조 파악 전에 코드를 수정하지 않는다\r
